# Gestión de Solicitudes Académicas

Sistema de consola en Java para registrar solicitudes de estudiantes, cambiar su estado, asignar un responsable, buscarlas y obtener un reporte.

## Ejecución

```
javac -encoding UTF-8 -d out src/main/java/ar/edu/utn/solicitudes/*.java
java -cp out ar.edu.utn.solicitudes.Main
```

Los datos se guardan en `solicitudes.csv`.
